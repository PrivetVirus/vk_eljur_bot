# VK Eljur Bot 🎓📘

Бот для социальной сети **ВКонтакте**, который служит мостом между ВК и школьным электронным дневником **ЭлЖур**.

**Особенности:**
- Написан на Python (`El.py`).
- Позволяет ученикам и родителям получать расписание, оценки и домашние задания прямо в личные сообщения ВК.
- Локальная база данных пользователей (`bot_database.db`, `users_data.csv`).
