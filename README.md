# 📘 VK Eljur Bot

**VK Eljur Bot** — это удобный и быстрый чат-бот для социальной сети **ВКонтакте**, созданный для интеграции со школьным электронным дневником **ЭлЖур**. Он позволяет ученикам и родителям моментально получать актуальное расписание, домашние задания и оценки прямо в личные сообщения ВК.

---

## 🚀 Особенности
- **🎓 Быстрая интеграция**: Привязка аккаунта ЭлЖур к профилю ВКонтакте за пару кликов.
- **📅 Расписание**: Получение расписания уроков на день или неделю вперёд.
- **📊 Оценки**: Моментальный просмотр текущих оценок по всем предметам.
- **📚 Домашние задания**: Удобный вывод актуальных ДЗ без необходимости заходить в браузер.
- **🔒 Безопасность**: Личные данные защищены и обрабатываются локально.
- **⚙️ База данных**: Эффективное хранение пользовательских сессий с использованием SQLite и CSV.

## 🛠 Технологии
- **Python 3.x**
- **vk_api** — библиотека для работы с API ВКонтакте
- **requests** — для выполнения HTTP-запросов к API ЭлЖур
- **SQLite3 / CSV** — для хранения пользовательских данных локально

## 📥 Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/PrivetVirus/vk_eljur_bot.git
   ```
2. Установите зависимости (если необходимо):
   ```bash
   pip install vk_api requests
   ```
3. Добавьте ваш токен ВКонтакте:
   - Откройте `El.py`
   - Замените `YOUR_VK_TOKEN_HERE` на ключ доступа вашей группы ВК.
4. Запустите бота:
   ```bash
   python El.py
   ```
